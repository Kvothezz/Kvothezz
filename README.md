* **Projeto em Destaque:**  **[Couch Club](https://github.com/Kvothezz/couch-club-api)** </br>
    Meu TCC da faculdade, que sigo mantendo e evoluindo ativamente com novas melhorias e refatorações. </br>
    É uma plataforma full-stack desenvolvida para resolver o clássico dilema de "o que vamos assistir hoje?", cruzando as listas de interesse de dois usuários para gerar um *match* de filmes em comum.
    *   **Back-end:** Construído como um monólito modular em **NestJS**, implementando o algoritmo de match entre usuários, banco relacional com PostgreSQL/Prisma e documentação viva via Swagger.
    *   **Front-end:** Interface interativa e responsiva construída com **React** e Vite, garantindo uma experiência fluida na exploração de catálogos e na visualização dos matches.
